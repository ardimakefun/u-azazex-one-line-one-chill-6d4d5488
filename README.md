## The line

> The ultrasound showed two heartbeats, and the doctor kept asking me, very quietly, which one was mine.

(102 characters, one sentence.)

## How it works

`main.ts` (Node 22, erasable TypeScript, no network, no randomness) writes the line deterministically to `/output/entry.txt`:

```sh
node main.ts
cat /output/entry.txt
```
